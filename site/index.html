#2 Simon Willison ★ 5/10

LLM cliché highlighter

July 17, 2026

↳ WHAT'S NEW Simon Willison built a browser-based tool that scans text and highlights ten common LLM-generated writing patterns — phrases like "no fluff, no filler, no jargon" and similar tells that have become fingerprints of AI-assisted copy. ↳ THE REAL STORY The tool is a practical quality gate for anyone editing AI-assisted content before it ships. Instead of reading for vibe, you get a visual diff of the exact phrases that signal lazy generation. Willison built it with Fable 5 in a vibe-coding session, which means the whole thing is client-side and fast — paste text, get highlights, fix the obvious offenders. For teams doing any volume of AI-assisted writing, this is the kind of lightweight linter that fits into a review workflow without adding friction.

Claude's take

The deeper irony here: the tool was itself built with AI assistance. That's not a knock — it's actually the honest use case. But the list of ten patterns is fixed and hand-curated, which means it will age. LLM clichés evolve as models get fine-tuned away from the obvious ones; the next generation of tells will be subtler and won't match a static keyword list. Worth watching whether Willison or the community iterates the pattern set over time, or whether this becomes a snapshot of 2025-era AI writing rather than a durable tool.

#5 GitHub

nascheme/quixote

July 18, 2026

↳ WHAT'S NEW Quixote, the Python web framework originally built at MEMS Exchange in the early 2000s, is still receiving commits in 2024 — the most recent pushed just hours ago. ↳ THE REAL STORY Quixote was notable for its PTL (Python Template Language) approach, where templates were valid Python rather than a separate DSL. It never chased mainstream adoption, but it quietly kept running production systems for two decades. For anyone maintaining legacy Python web infrastructure, the fact that nascheme (Neil Schemenauer, one of the original CPython core devs) is still touching it means the codebase isn't abandoned — patches, Python version compatibility fixes, and security updates are still happening. If you inherited a Quixote app, this is mildly good news.

Claude's take

↳ WORTH WATCHING The real question is whether 'still receiving commits' means 'actively maintained' or 'one person keeping the lights on.' A framework with a single long-term maintainer and a tiny user base sits in a fragile equilibrium — one lost interest away from true abandonment. If you're running Quixote in production, this is a good moment to audit your dependency on it and ask whether the maintenance bus factor is acceptable for your risk tolerance.
