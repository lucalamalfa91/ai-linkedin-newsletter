#1 Latent Space ★ 8/10

Loopcraft: The Art of Stacking Loops

June 12, 2026

↳ WHAT'S NEW Latent Space surfaces a conceptual framework called "Loopcraft" — coined or discussed by Peter Steinberger, Boris Cherny, and Andrej Karpathy — focused on the practice of stacking feedback loops when building with AI agents. ↳ THE REAL STORY The core idea is that effective AI-assisted development isn't a single prompt-response cycle but a deliberate layering of loops: inner loops for tight code iteration, outer loops for validation and testing, and meta-loops for evaluating whether the whole system is moving in the right direction. For practitioners building agents or copilot-style tooling today, this reframes the design question from "what prompt works" to "what loop architecture works" — which has direct implications for how you structure evals, when you inject human checkpoints, and how you avoid compounding errors across long agentic runs.

Claude's take

The concept is credited to three high-profile names, which gives it credibility, but the actual substance here is thin from the excerpt alone — this reads more like a framing device than a technical specification. The risk is that "stacking loops" becomes another piece of AI jargon that sounds actionable but stays abstract. Worth watching whether Steinberger, Cherny, or Karpathy publish concrete implementations or whether this stays at the level of conference-talk metaphor.

#2 Simon Willison ★ 7/10

Claude Fable is relentlessly proactive

June 11, 2026

↳ WHAT'S NEW Claude Fable 5 is drawing attention for a behavioral shift: the model is described as "relentlessly proactive" — it actively deploys a wide range of capabilities to reach a goal rather than waiting for explicit instruction at each step. ↳ THE REAL STORY Simon Willison, who builds real tools with these models daily, is flagging a qualitative change in agentic behavior after two days of hands-on use. This isn't about benchmark scores — it's about the model's disposition during multi-step tasks. A model that anticipates next steps, reaches for tools unprompted, and chains actions without being nudged changes how you structure prompts and how much you need to babysit an agent loop. For developers building on top of Claude via API, this could mean fewer round-trips and less scaffolding — but also less predictable intermediate states.

Claude's take

A model that's proactive by default is useful right up until it isn't. The same trait that makes it finish tasks faster also makes it harder to pause, inspect, or redirect mid-execution. If Fable 5 is reaching for tools and taking actions before you've confirmed the direction is right, you're debugging outcomes rather than steering decisions. Worth watching how this plays out in workflows where human-in-the-loop checkpoints matter — and whether Anthropic ships any knobs to dial the proactivity back when you need it.

#3 Datasette Project

Datasette 1.0a33 with JSON extras in the API

June 11, 2026

↳ WHAT'S NEW Datasette 1.0a33 extends the `?_extra=` query parameter — previously limited to table endpoints — to cover query and row API endpoints as well. The release moves the project closer to a stable 1.0. ↳ THE REAL STORY The `?_extra=` pattern lets API consumers request only the response fields they actually need, rather than receiving a fixed payload shape. With it now covering queries and rows, you can trim API responses across all three major endpoint types — tables, arbitrary SQL queries, and individual row lookups. For anyone building on top of Datasette's JSON API, this means less parsing overhead and smaller payloads, especially relevant when querying large result sets or running Datasette behind a bandwidth-constrained edge.

Claude's take

The project is still in alpha — 1.0a33 means thirty-three alpha releases since the 1.0 cycle started. The `?_extra=` pattern itself dates back to 1.0a3 in August 2023, so the API surface has been evolving for well over a year without a stable release. Anyone building production tooling on top of these endpoints should treat the interface as still subject to change, even if this release signals the design is converging.
