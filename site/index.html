#1 Simon Willison ★ 7/10

Reverse-engineering is cheap now

July 20, 2026

↳ WHAT'S NEW Simon Willison's observation: coding agents have collapsed the cost of reverse-engineering home devices to the point where it's now a routine weekend project rather than a specialist undertaking. ↳ THE REAL STORY The ROI calculation on reverse-engineering has flipped. Before agents, the work was technically feasible but economically irrational for most people — hours of effort to automate one device, with the knowledge rarely transferable. Now the same task takes a fraction of the time, and the agent handles the tedious parts: sniffing traffic, writing the integration code, iterating on failures. The practical result is that any developer with a home device and mild curiosity can now produce working automations that previously required either deep expertise or a dedicated weekend. This isn't about capability — it's about friction. When friction drops far enough, behavior changes at scale.

Claude's take

The catch nobody is talking about: the same dynamic applies to less benign targets. If reverse-engineering a smart thermostat is now a casual afternoon task, so is probing the protocol of a neighbor's garage door opener or a cheap IoT lock. The security community has long operated on the implicit assumption that reverse-engineering effort acts as a natural barrier. That barrier is eroding fast, and most consumer device manufacturers are not updating their threat models to match.
