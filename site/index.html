#1 Simon Willison ★ 9/10

datasette-agent 0.2a0

June 10, 2026

↳ WHAT'S NEW datasette-agent 0.2a0 adds mid-execution user interaction to tools: any tool declaring a `context` parameter receives a `ToolContext` object and can call `await context.ask_user(...)` to pause and prompt the user before continuing. ↳ THE REAL STORY This closes a real gap in agentic database workflows. Previously, an agent querying a Datasette instance had to either commit to an action with whatever context it had at invocation time, or fail and restart. With `ask_user`, a tool can hit an ambiguous branch — say, multiple matching table names or an unclear filter — and surface a clarifying question inline rather than hallucinating a choice or bailing out entirely. For developers building chat-style interfaces on top of Datasette, this means fewer silent wrong answers and a more natural back-and-forth loop without wiring up a separate clarification layer.

Claude's take

The excerpt is truncated, so the full scope of 0.2a0 isn't visible — there may be more to this release. The bigger open question is how `ask_user` behaves in non-interactive or automated pipeline contexts: if a tool blocks waiting for human input inside a batch job or a scheduled query, you need a timeout or fallback path, otherwise you've introduced a silent hang. Worth checking the release notes for how ToolContext handles the headless case before wiring this into anything unattended.

#2 Google ★ 8/10

DiffusionGemma

June 10, 2026

↳ WHAT'S NEW Google released DiffusionGemma, an open-weights diffusion-based language model — a public release following a brief experimental Gemini Diffusion preview in May 2025 that briefly appeared and disappeared. ↳ THE REAL STORY Diffusion LMs generate text by iteratively denoising an entire output in parallel rather than predicting one token at a time left-to-right. The practical upshot: the May preview was clocked at 857 tokens/second — a number that makes autoregressive models look slow by comparison. For developers building latency-sensitive applications (real-time agents, streaming interfaces, high-throughput batch jobs), that generation speed changes the cost-per-token math significantly. Being open-weights means you can run it locally or on your own infrastructure, which matters if you want that speed without routing through Google's API.

Claude's take

↳ WORTH WATCHING Speed is the headline, but diffusion LMs have historically struggled with instruction-following quality and factual accuracy compared to autoregressive models at equivalent parameter counts — the parallel denoising process doesn't have the same sequential reasoning chain that makes autoregressive models reliable for structured tasks. 857 tokens/second means little if output coherence degrades on anything beyond short, simple completions. The open question: at what task complexity does the quality gap become a real problem, and has Google actually closed it here or just shipped a fast model that's good at benchmarks?

#5 Simon Willison ★ 2/10

Quoting Jeremy Howard

June 10, 2026

↳ WHAT'S NEW Jeremy Howard proposed a governance mechanism for slowing recursive AI self-improvement: the lab holding the top-ranked model would be barred from using that model on frontier AI development, while everyone else retains access to it. ↳ THE REAL STORY The logic is structural rather than regulatory. If the leading lab can't use its own best model to build the next one, the compounding feedback loop — model helps design better model — gets interrupted at the source. Other researchers and builders still get the capability; only the self-improvement cycle at the frontier gets throttled. It's a targeted constraint, not a blanket ban.

Claude's take

The excerpt cuts off mid-sentence on what Howard calls the 'critica[l]' second property of the proposal — which is exactly the part that would determine whether this is workable or not. What's missing matters: enforcement, definition of 'top-ranked', and who adjudicates when a model crosses that threshold are all unresolved. There's also an obvious evasion surface — a lab could use a model ranked second, or spin out a separate entity to do the frontier work. The idea is worth taking seriously, but the hard part isn't the principle; it's the verification.
