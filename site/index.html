#2 Hugging Face ★ 7/10

tencent/Hy3

July 6, 2026

↳ WHAT'S NEW Tencent released Hy3, a 295B-parameter Mixture-of-Experts model under Apache 2.0 license. It activates 21B parameters per forward pass plus 3.8B Multi-Token Prediction layer parameters. The release follows a preview launched in late April that was tested across 50+ internal Tencent products. ↳ THE REAL STORY The 21B active parameter count is the number that matters for inference cost — not the 295B headline. At that activation size, you're in the same ballpark as Mistral's MoE-class models in terms of compute per token, while the full parameter pool gives the model broader knowledge capacity. Apache 2.0 means you can fine-tune, deploy commercially, and modify without royalty friction. For teams evaluating open-weight frontier models, Hy3 is now a legitimate candidate alongside Mixtral and DeepSeek-V3 — especially if you're already running Chinese-language workloads where Tencent's training data mix likely shows.

Claude's take

The 50+ products feedback loop sounds like a quality signal, but it's also a selection effect — Tencent's internal use cases skew heavily toward consumer apps, gaming, and ad systems. How the model performs on code generation, structured reasoning, or technical English tasks is still an open question until independent evals land. Also worth noting: 295B total parameters means checkpoint storage and loading overhead is substantial even if inference is cheaper. Anyone planning to self-host should budget for the weight distribution problem before getting excited about the active-parameter efficiency story.
