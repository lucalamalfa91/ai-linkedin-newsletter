#1 DeepReinforce ★ 8/10

Ornith-1.0: Self-Scaffolding LLMs for Agentic Coding

June 29, 2026

↳ WHAT'S NEW DeepReinforce released Ornith-1.0, an open-weights (MIT) family of agentic coding models in four sizes: 9B Dense, 31B Dense, 35B MoE, and 397B MoE. Built on top of Gemma 4 and Qwen 3.5 base models, it's the lab's first public release. ↳ THE REAL STORY The headline concept is "self-scaffolding" — the model generates its own agentic loop structure rather than relying on an external orchestration framework. In practice, that means fewer moving parts when building coding agents: no LangGraph, no custom tool-calling harness bolted on top. If it holds up, you get a single model call that handles task decomposition and execution planning internally. The MIT license means you can run it commercially without negotiating terms, and the MoE variants (35B and 397B) offer a path to larger capability at lower active-parameter cost if you have the hardware to serve sparse models.

Claude's take

The excerpt cuts off before any benchmark numbers land, which is a red flag worth noting. "State-of-the-art" claims without visible evals on SWE-bench or similar are easy to make on a launch page. The self-scaffolding framing is also conceptually interesting but underspecified — it's unclear whether this is a training-time property (the model was RL-trained to produce structured agentic traces) or just prompt engineering baked into the system prompt. That distinction matters enormously for reliability in production. Worth waiting for independent evals before routing real coding tasks through it.

#2 Simon Willison ★ 2/10

HTML table extractor

June 29, 2026

↳ WHAT'S NEW Simon Willison added an HTML table extractor to his tools collection at tools.simonwillison.net. Paste rich text from a browser — including embedded HTML tables — and it converts every detected table into HTML, Markdown, CSV, TSV, or JSON. ↳ THE REAL STORY The friction of getting a web table into a usable format is genuinely annoying: copy from Wikipedia, get garbage in your spreadsheet or prompt. This tool handles the clipboard's rich-text format directly, so you skip the 'paste into Google Sheets, export as CSV, clean up encoding' loop. Five output formats means it fits whether you're feeding data to a model, dropping it into a notebook, or writing documentation.

Claude's take

↳ WORTH WATCHING Willison's paste-conversion tools are client-side and single-purpose by design — which is the right call for trust and speed. The open question is edge cases: nested tables, merged cells (colspan/rowspan), and tables built with CSS rather than actual

tags all break naive extractors. The excerpt cuts off mid-sentence on the Wikipedia demo, so it's unclear how gracefully it handles those. Worth testing on a real-world messy table before you rely on it in a pipeline.

#3 Simon Willison ★ 1/10

Count the number of Safari tabs

June 29, 2026

↳ WHAT'S NEW Simon Willison shared a one-liner AppleScript command to count open Safari tabs via the terminal: `osascript -e 'tell application "Safari" to count tabs of every window'` ↳ THE REAL STORY Not much of a story here — this is a genuine TIL micro-post, not a product announcement. The practical value: if you're scripting macOS workflows, automating browser state checks, or building context-gathering tools for local AI agents, AppleScript's Safari bridge is alive and usable from the command line with zero setup. The command returns an integer instantly. Willison's count was 370 tabs, which is either a confession or a warning.

Claude's take

↳ WORTH WATCHING The interesting thread to pull: AppleScript access to Safari goes well beyond tab counts — you can read URLs, titles, and page content from every open tab. That's a non-trivial local data source for anyone building personal AI assistants or context-aware tools on macOS. The catch is that Apple's direction with automation is unclear; Shortcuts has been the official successor narrative for years, yet AppleScript still works where Shortcuts can't reach. Betting a workflow on it carries some platform risk.
